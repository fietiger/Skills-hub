# 邮件发票自动下载技能

此技能用于从指定的 163 邮箱中自动化获取电子发票。它能够处理直接的 PDF 附件，也能处理隐藏在分享链接（如 51发票、诺诺网）后的发票。

## 使用场景

- 需要批量从邮箱提取电子发票进行报销时。
- 收到大量 51发票或诺诺网的交付邮件，不想手动逐一点击下载时。
- 邮箱中充斥着网易官方广告邮件，需要自动清理时。

## 核心功能

1. **多源下载**：
   - **PDF 附件**：直接保存邮件中的 PDF 附件。
   - **51发票链接**：自动解析 `dlj.51fapiao.cn` 链接并下载。
   - **诺诺网链接**：使用 Playwright 模拟浏览器环境，自动截获 `nnfp.jss.com.cn` 的真实下载地址。
2. **邮件清理**：自动识别并删除来自 `member@service.netease.com` 的广告邮件。
3. **备份机制**：若无法直接获取 PDF，会将邮件原文保存为 HTML 文件，方便人工后续处理。
4. **适配 163 邮箱**：内置 ID 指令发送逻辑，确保 IMAP 登录安全。

## 工作流程

1. **连接邮箱**：使用 `basicinfo.md` 中的配置连接 163 IMAP 服务器。
2. **过滤邮件**：
   - 删除广告邮件。
   - 筛选主题包含“发票”或“行程单”的邮件。
3. **解析与下载**：
   - 优先下载 PDF 附件。
   - 若无附件，解析 HTML 内容中的交付链接并调用对应的下载引擎。
   - 若下载失败，保存 HTML 备份。
4. **清理**：永久删除已标记的广告邮件并退出。

## 使用指南

直接运行 `scripts/download_emails.py` 即可开始同步：

```bash
python scripts/download_emails.py
```

### 依赖项

- `playwright`：用于处理动态渲染的诺诺网页面。
- `requests`：用于常规网络请求。
- `imaplib` & `email`：Python 标准库，用于邮件处理。

### 配置说明

邮箱账号、授权码等敏感信息应配置在项目根目录的 `.trae/rules/basicinfo.md` 中。
