# 发票汇总合并器 (Invoice Summary Merger)

**Description:** 将所有不同来源的发票（包括二维码下载、邮箱下载等）汇总到统一的发票汇总文件夹中，并按类型进行分类管理。

## 功能说明
此技能用于自动化合并分散在不同目录中的各类发票文件，将它们整合到统一的目录结构中，并按发票类型进行分类存放。

## 使用场景
- 整合来自不同渠道的发票（二维码扫描、邮箱下载等）
- 按发票类型（住宿、交通、餐饮等）进行统一管理
- 为后续的报销或财务处理提供有序的发票集合

## 核心功能
1. **多源汇总**：自动搜索并收集来自不同目录的发票文件
2. **智能分类**：按发票类型（住宿发票、滴滴车票、火车票、餐费发票、其他发票）进行分类
3. **防重复处理**：自动检测并处理同名文件，避免覆盖
4. **目录结构维护**：创建标准化的发票分类目录结构

## 使用方法
直接运行 `scripts/create_invoice_summary.py` 脚本即可开始汇总：
```bash
python scripts/create_invoice_summary.py
```

## 操作流程
1. 搜索所有已知的发票存储目录
2. 按发票类型分类读取PDF文件
3. 将所有发票文件复制到统一的"发票汇总"目录
4. 按类型分别存放在对应的子目录中
5. 输出汇总统计信息

## 输出结果
- 创建 `发票汇总/` 目录
- 在其中创建以下分类子目录：
  - `住宿发票/`
  - `滴滴车票/`
  - `火车票/`
  - `餐费发票/`
  - `其他发票/`
