# 通用发票信息提取器 (General Invoice Extractor)

**Description:** 从PDF格式的发票中提取关键信息（如开票日期、金额、买卖双方信息等）并汇总为Excel表格的技能。

## 功能说明
此技能用于自动化提取各种PDF格式发票中的结构化数据，能够识别发票中的关键字段并生成统一格式的Excel汇总表。

## 使用场景
- 从多种类型的发票PDF文件中提取结构化数据
- 将发票信息汇总到Excel表格进行财务处理
- 自动化发票信息录入和整理

## 核心功能
1. **通用发票解析**：支持多种发票格式的PDF文件解析
2. **信息字段提取**：自动识别并提取以下关键字段：
   - 文件名
   - 开票日期
   - 金额（优先提取价税合计金额）
   - 购买方名称及识别号
   - 销售方名称及识别号
3. **智能金额识别**：优先提取价税合计金额而非不含税金额
4. **Excel输出**：生成标准化格式的Excel汇总表

## 使用方法
直接运行 `scripts/extract_general_invoices.py` 脚本：
```bash
python scripts/extract_general_invoices.py <输入目录> <输出Excel文件>
```

例如：
```bash
python scripts/extract_general_invoices.py "发票汇总\住宿发票" "住宿发票信息汇总.xlsx"
```

## 提取字段说明
- **文件名**：PDF文件的原始名称
- **开票日期**：发票开具的日期
- **金额**：发票的价税合计金额（含税总额）
- **购买方名称**：发票上的购买方单位名称
- **购买方识别号**：购买方的纳税人识别号
- **销售方名称**：发票上的销售方单位名称
- **销售方识别号**：销售方的纳税人识别号

## 特殊处理
- 优先提取价税合计金额（含税金额）而非不含税金额
- 支持中文大写金额识别（如"肆拾圆整"）
- 智能识别不同格式的发票布局
